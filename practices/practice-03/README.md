## 4. Задание 1. Эксперименты с DOM и событиями

Страница: `http://127.0.0.1:5503/examples/dom-events.html`

| № | Прогноз до запуска | Фактический результат | Причина |
|:-:|:------------------|:----------------------|:--------|
| 1 | `querySelector("#missing")` вернёт `null`, `querySelectorAll(".missing")` — пустой NodeList | `missing = null`, `empty.length = 0`, обращение к `missing.textContent` → `TypeError` | Отсутствующий элемент не найден |
| 2 | `dataset.taskId` — строка; после `Number()` — число | До: `"23"` (string). После: `23` (number) | `dataset` всегда возвращает строки |
| 3 | Сохранённый `initialItems` не увеличится, новый запрос вернёт актуальное | `initialItems.length` = 1, новый = 3 | `NodeList` из `querySelectorAll` — статический снимок |
| 4 | Строка с `<strong>` отобразится текстом | В `h3` нет дочерних элементов | Использован `textContent` |
| 5 | Клик по вложенному `span` даст фазы 1 → 2 → 3 | `capture outer phase=1`, `bubble btn phase=3`, `bubble outer phase=3` | Событие всплывает от `span` к `button` и контейнеру |

### Отладка

Точка останова в обработчике кнопки:

- `event.target` — вложенный `span` или `button`;
- `event.currentTarget` — сам `button`;
- `event.eventPhase` — 2 или 3.

## 6. Задание 3. Делегирование, изменение статуса и удаление

Реализован `handleTaskListClick` в `src/main.js`. Подписка навешана один раз на `#task-list`.

Порядок:

1. Проверка `event.target instanceof Element`.
2. `closest("button[data-action]")`.
3. Проверка действия `toggle` / `delete`.
4. `Number(dataset.taskId)` + `Number.isSafeInteger`.
5. `findTaskById` → `setTaskCompleted` / `removeTask`.
6. При отказе — сообщение, массив не меняется.
7. При успехе — сохранение, `renderApp`, `restoreTaskFocus`.

Проверено: клик по вложенному `span`, двойное переключение, удаление, подмена `data-task-id="4abc"`.

## 7. Задание 4. Фильтры, сводка и пустые состояния

`getVisibleTasks(tasks, filter)`:

| Значение | Результат |
|---|---|
| `all` | новый массив всех задач |
| `pending` | только `completed === false` |
| `completed` | только `completed === true` |

`renderSummary` обновляет `[data-stat="total"]`, `completed`, `pending`, `progress`, `visible`.

`renderEmptyState` различает:

- `total = 0, visible = 0` → «Список задач пуст.»
- `total > 0, visible = 0` → «Нет задач по выбранному фильтру.»
- `visible > 0` → скрыто
