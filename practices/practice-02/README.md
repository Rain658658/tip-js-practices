### Исправление эксперимента 2

Исходный код:

```js
const square = (value) => {
  value * value;
};
```

Проблема: стрелочная функция с телом в фигурных скобках не возвращает значение без явного `return`. Результат вызова — `undefined`.

Исправление:

```js
const square = (value) => {
  return value * value;
};
```

Результат после исправления: `square(4) → 16`, тип `number`.

# Задание 2. Модель данных

Модель задачи:

```js
{
  id: 20,
  title: "Подготовить демонстрацию",
  completed: false,
  priority: "medium"
}
```

| Поле        | Правило                                                                        |
| ----------- | ------------------------------------------------------------------------------ |
| `id`        | Положительное безопасное целое: `Number.isSafeInteger(id) && id > 0`.          |
| `title`     | Строка. После `trim()` длина от 1 до 100. В объект пишется очищенное значение. |
| `completed` | Логическое значение. При создании всегда `false`.                              |
| `priority`  | Строго `"low"`, `"medium"` или `"high"`. По умолчанию `"medium"`.              |

Функция `createTask` возвращает либо `{ ok: true, task }`, либо `{ ok: false, error: "..." }`.

### Контракт

Функция `getPrioritySummary(tasks)` размещена в отдельном модуле `src/task-extra.js`

- `tasks` — корректный массив задач модели.
- Возвращает новый объект фиксированной формы:

  ```js
  {
    low:    { total: 0, pending: 0 },
    medium: { total: 0, pending: 0 },
    high:   { total: 0, pending: 0 }
  }
  ```

- Все три ключа присутствуют всегда, даже если задач соответствующего приоритета нет.
- `total` — общее количество задач приоритета, `pending` — количество невыполненных.
- Исходный массив и его объекты не изменяются.
- Для реализации использован цикл `for...of`; сторонние библиотеки и `reduce` не применяются.
